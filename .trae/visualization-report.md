3. **PowerShell 策略** - 脚本执行策略限制，需要提前配置
4. **f-string 格式化** - 按钮 key 使用 f-string 时忘记加 `f` 前缀

## 💡 经验总结

### 成功经验
1. **模拟数据驱动开发** - 在后端未完成时，使用模拟数据可以快速完成 UI 开发
2. **组件化设计** - 每个功能独立封装，便于维护和复用
3. **渐进式开发** - 先完成 UI，再对接数据，最后优化性能

### 踩过的坑
1. **Streamlit 刷新机制** - 需要理解 Streamlit 的运行机制，避免无效刷新
2. **布局优化** - 多列布局需要合理设置列宽比例
3. **数据展示** - 大数据量时需要分页或虚拟滚动

### 改进建议
1. 建议添加组件库，统一 UI 风格
2. 建议添加主题配置，支持深色模式
3. 建议添加国际化支持
